# 行序 · LineRename

**一行文字，一个新名字。** 与拾序 SmileFile 统一视觉风格的浏览器批量重命名工具。

[打开在线工具](https://cut-hand.github.io/LineRename/)

## 使用

1. 使用 Windows / macOS 的 Chrome 或 Edge 打开网站。
2. 选择文件夹，授权读写，再选择需要改名的文件。
3. 左侧粘贴名称（每行一个，空行忽略），右侧自然排序或上移、下移调整文件。
4. 核对原文件名、新文件名和状态，执行重命名。
5. 点击“撤销上次”恢复；关闭页面后可以选择同一文件夹，通过“从备份恢复”读取历史记录。

默认保留每个文件原扩展名。非法名称、外部文件占用和重复目标会跳过；允许批次内互换名称。仅处理所选目录最外层的文件，不改目录名、不递归扫描。文件内容始终在本地处理，不上传。

## 浏览器版的恢复机制

每次执行先将原文件复制到所选目录内的 .linerename-backup- 开头的独立目录，进行 SHA-256 校验，再删除原名称并写入目标名称。备份与 journal.json 会保留，撤销先校验文件，避免覆盖后来修改的内容。失败时会尝试恢复，恢复受阻则保留备份供手动检查。

此流程需要额外磁盘空间，大文件校验也需要内存，可能改变修改日期和其他文件元数据。执行中请勿关闭页面、编辑或同步正在处理的文件。确认不再需要恢复后，可自行删除备份目录。

## 项目结构

- index.html：界面
- style.css：样式
- app.js：页面交互与文件选择
- core.js：名称规划、校验和可恢复的文件操作
- core.test.cjs：核心逻辑测试（运行 node core.test.cjs）

无需依赖、无需构建。GitHub Pages 从 main 分支根目录发布。旧桌面实现已从当前版本移除，可通过 Git 历史查阅。
